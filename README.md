trial_model_one.m - This CNN isdesigned for small image inputs (128×128×3). It begins with an input layer followed by two convolutional blocks: the first uses 16 filters and the second 32 filters (both 3×3 with same padding), each followed by a ReLU activation and 2×2 max pooling to progressively extract features and reduce spatial dimensions. The extracted features are then passed directly to a fully connected layer that maps them to the number of output classes, followed by a softmax layer for probability distribution. The final classification layer incorporates class weights to handle class imbalance during training. Overall, it’s a lightweight CNN with two feature-extraction stages and no deep stacking or dropout, suitable for basic image classification tasks. It is a 2 layer custom CNN on Matlab. The model is intentionally built shallow and simple, since the dataset it was trained and validated on was very small(116-Aggregate images, 93-Control images) and binary classification task was rather simple and straight-forward. We did not require millions of feautre extraction and a higly complex non-linear space for this classification task, where other pretrained models would have been more harmful than helpful and caused overfitting. 
try_count_two.m - uses traditional image processing methods, for detecting and counting aggregates. The image is read using imread and displayed, and an interactive loop with ginput lets the user click on pixels to inspect their RGB intensity values and input a threshold value(mv). The RGB channels are separated into R, G, B, and the green channel is visualized since the objects of interest are prominent there. A binary mask (BW) is created using three logical conditions: low red, high green, low blue for isolating green fluorescent objects of interest in the images based on mv value. The binary image is cleaned using 'bwareaopen' to remove small noisy regions (objects with fewer than 5 pixels). Connected components (bwconncomp) are computed to identify distinct objects (aggregates). 'regionprops' extracts bounding boxes for each detected object. Finally, the bounding boxes are overlaid on the image to visualize detected aggregates and display their count.
